AXIOM PROTAGONIST PROFILER
=========================
Run from the backend folder.

Preview:
  python -m profiler.profile_protagonist NOVEL_ID

Preview and save:
  python -m profiler.profile_protagonist NOVEL_ID --save

Options:
  --protagonist "Name"        Override automatic character detection
  --comments FILE            Read a UTF-8 comments file
  --no-fetch-comments        Use synopsis and tags only
  --minimum-name-confidence 75
  --save                     Offer to save after preview
  --yes                      Save without confirmation; requires --save

The default profile measures seven traits: intelligence, charisma, moral integrity,
kinship/friendship, romantic attachment, erotic desire, and arrogance/conceit.
The active traits and prompts come from Manage Protagonist Profile in the Admin Hub.

Re-profile every novel that is missing any of the currently configured scores
(e.g. after the trait set changed):
  python -m profiler.regenerate_profiles --dry-run --limit 3
  python -m profiler.regenerate_profiles --sleep 2
  python -m profiler.regenerate_profiles --all        # redo every novel
  python -m profiler.regenerate_profiles --novel-ids 12 15 40

The profile_all command remains a compatibility entry point for this profile.

Required backend/.env values:
  SUPABASE_URL
  SUPABASE_PUBLISHABLE_KEY
  SUPABASE_SECRET_KEY
  GEMINI_API_KEY
Optional: GEMINI_MODEL
